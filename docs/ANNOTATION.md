# 标注目标：你听到的主旋律乐谱

- 保留主唱和承担主旋律的对唱接替；不单独标注背景和声、叠唱和 delay。
- 乐谱需要的转音与半音 ABA 要保留；未记谱的滑入、颤音和气声不要切成独立音符。
- 无明确旋律音高的念白、换气或无意义漏气通常不标；不是把所有说唱一概删除。
- 同一音符尾部变成气声，可作为原音符的一部分；完全听不出音高、纯靠猜测的独立气声
  不宜直接作为确定的声学音高标签。当前 MIDI-only 标签没有置信度字段。
- 辅音/元音边界不一定等于节奏音头，同一个元音也可能包含多个必要转音。
- 音符按乐谱节奏标注，straight 和 triplet 的选择按小节评估；跨小节音符两端分别处理。
- 保留前奏、间奏与尾奏的空白；不要把第一个人声音符移动到第一小节。
- 使用 PPQ 480、正确的 tempo map 和 WAV START；变速歌不能只用单一速度强行对齐。
- 少量误标不必导致全盘返工，发现时修正；保持整体标准一致，避免同类背景声反复标成主旋律。

监督模型学习的是这些编辑决策。训练时应保留输入中的干扰，并在目标 MIDI 中排除它们，
而不是只提供永远没有和声、没有气声的理想音频。
